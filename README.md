# Interactive Study Cards

A simple web application built as part of the TripleTen AI-assisted Software Engineering program. It allows users to view and study flashcards through an interactive interface.

## Features

- Interactive Flashcards
- Responsive design
- Easy-to-use interface
- Open Deck View
- Carousel/Practice View

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- Github
